# 整えサロン DM作成

毎月のDM（A4・2枚）を作り、封筒の宛名まで印刷できる、ビルド不要の1枚HTMLアプリです。
目的は、お客様の健康向上と、サロンを思い出してもらうこと。結果としてリピート率を上げること。

## 使い方

`index.html` をブラウザで開くだけです（インストール不要）。

1. 「⑤ サロン情報」でサロン名・電話・住所・予約QRを登録
2. 「② お客様」でお客様を登録（Excelからの貼り付け可）
3. 「① 今月のDM」で文面を整える（AIで下書きも可）
4. 「③ 印刷」で、DMと封筒の宛名（長形3号・縦書き）を印刷
5. 「④ 効果測定」でクーポンNo.から反応を記録

## 主な機能

- 月別の文面12か月分×2パターン（年ごとに自動で切り替え）
- 季節のイラスト（コード内で描画）
- 文字サイズ（標準／大／特大）とお客様ごとの指定、はみ出しの自動調整
- 来店周期・休眠・誕生月による送付先の推薦と、お客様ごとの差し込み
- 次回予約メモ欄・紹介特典・できた日カレンダー
- リピート導線チェック、効果測定（反応率・費用対効果）
- AI下書き（自動モード／指示書モード。APIキー直接 or プロンプトのコピー）

## データの保存場所

お客様情報・文面・記録はすべて、**使用しているブラウザの中（localStorage）**に保存されます。
このリポジトリには含まれません。外部サーバーには送信されません。

- ブラウザが違う、PCが違う、サイトデータを消す、と見えなくなります
- 「⑤ サロン情報」のバックアップ機能で、月1回以上保存してください
- Claude APIキーは別領域に保存され、バックアップには含まれません

## 注意

- 個人情報（氏名・住所）を扱います。バックアップファイルやCSVの保管にご注意ください
- 文面は医療広告ガイドラインに配慮し、効果の断定を避けています。AIの下書きは必ず目を通してから使用してください
